# Fillout 落地配置（照此设置即可实现答案驱动显隐）

Fillout 的显隐能力叫 **Conditional Logic**，挂在题目上，在右侧面板「Logic」里配置。本表所有规则都能用下面 4 种模式实现：

| 模式 | 适用本表的题 | Fillout 配置方法 |
|:---|:---|:---|
| ① 按身份分流 | 性别专属、上下位专属 | 题目 → Logic → **Show if** → `Q-GATE-01` **is** `女S` 或 `女M` |
| ② 按兴趣门折叠 | 26 大类 × 15 维度（416 题） | 每个大类先放一道门题，该大类所有维度题 → **Show if** → 门题 **is not** `不感兴趣` |
| ③ 按答案追加 | 多人场景等（如 Q-E10） | 题目 → **Show if** → `Q-E09` **is** `是` |
| ④ 跳过整段 | 兴趣门选「不感兴趣」 | 用 **Page/Section 分支**：门题放在段落开头，段落 → Logic → 整段按门题显隐 |

**配置顺序建议**：

1. 先建 `Q-GATE-01`（身份）与 `Q-GATE-02`（取向），放第一页
2. 建通用模块（二、四、五、六、八、九、十），不加条件
3. 建性别专属题（16 女性 + 5 男性），加 `Show if` 身份条件
4. 建上下位专属题（7 S + 11 M），加 `Show if` 身份条件
