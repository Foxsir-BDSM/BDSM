# _dev · 开发资料

本目录存放**开发过程产物**：文档、数据表、作业流程、历史归档。
**不参与构建**（已在 `vite.config.js` 的 watch ignore 与构建输入中排除）。

> 运行所需的文件都在仓库根目录（`src/` `tools/` `dist/` 等）。
> 根目录只保留运行所需，开发资料一律进这里。

---

## 目录结构

```
_dev/
├── docs/                    开发文档
│   ├── 项目介绍.md               ★ 对外简介（给他人看的）
│   ├── 架构设计/                 分层设计、重构方案、功能清单基线
│   ├── 操作手册/                 环境搭建、第三方服务对接步骤
│   ├── 验证记录/                 测试与验证流程
│   ├── 数据表/                   题库、字段映射、维护对照表、生成物
│   └── 草稿/                     已过时的中间产物（留档备查）
├── sop/                     标准作业流程
└── archive/                 历史归档（按主题 + 时间线，见下表）
```

### 几个归档的背景

**`2026-10-03_zite自动化尝试/`**
曾尝试用 CDP 浏览器自动化清理表单字段，结果因坐标失效与事件模拟不可靠，**反而误加了几十个字段**。
尝试中止，脚本归档并附失败分析。教训：坐标点击在可滚动画布上不可靠，应在首次「数量没减少」时就停下。

**`2026-10-04_数据库迁移/`**
数据库从 `0019555500b60c58 / taRmZxGFzF5` 迁到 `e7d18ead20743825 / t4d3B3XvKL8`。
内含：新库探测、新旧字段对比、写入格式探测、表单入口验证。

**`2026-10-04_工具迁移/`**
最大的归档区，混合了不同时期的产物：一次性迁移脚本、题库分析脚本、以及若干被后续实现取代的探针。
按时间看横跨 10-02 到 10-04，故未再细分。

## 新增归档的约定

1. 目录名用 `日期_主题` 格式（如 `2026-10-05_xxx`）
2. 同一主题的文件放同一目录
3. 若归档内容有「失败/放弃」背景，在目录里放一个 `README.md` 说明原因
4. 归档后**在本文件的归档时间线表里补一行**
