## 变更二：全站路由权限放宽

### 单一开关

新增 **`src/shared/config/access.js`**：

```js
export const RELAXED_ACCESS = true;   // true = 全站放宽；false = 恢复管控
```

改这一行即可全局生效，**这是唯一的开关**。

### 影响范围（2 处）

| 文件 | 放宽后的行为 |
|:---|:---|
| `src/shared/js/guard.js` | `initGuard()` 直接 return，不做任何重定向 |
| `src/shared/js/registry.js` | `getVisibleProjects()` 跳过角色白名单与维护态，返回全部非 offline 模块 |

### 具体效果

| 场景 | 之前 | 现在 |
|:---|:---|:---|
| 未登录访问 `/index.html` | 重定向 → `/landing.html` | ✅ 正常打开 |
| 未登录访问 `/admin.html` | 跳首页 | ✅ 正常打开（自身鉴权仍提示权限不足） |
| 未登录访问 `/modules/*` | 无守卫，可访问 | ✅ 不变 |
| 未登录看探索区 | 「暂无可用项目」 | ✅ **6 个模块卡全部展示** |
| 浏览器控制台 | — | 输出提示：`[guard] 路由管控已放宽…` |

### 保留的限制（有意为之）

放宽的是**路由可达性**，不是**操作权限**。以下仍按原逻辑限制：

- 知识区/任务区的发布、删除按钮（按角色显隐）
- 管理后台的用户权限与档案管理（`initAdmin` 鉴权）
- 个人资料页的头像/昵称编辑（未登录显示游客卡）
- 档案馆的角色字段白名单与隐私开关过滤

### 恢复方式

发布前把 `RELAXED_ACCESS` 改为 `false` 即可，无需改动其他代码。

## 变更三：顶栏改为类微信用户菜单 + 新增个人资料页

### 3.1 顶栏改造（`src/launcher/index.html`）

**改造前**：头像（可点上传）+ 昵称 + 等级称号药丸 + 管理按钮 + 登出按钮，全部平铺在顶栏。

**改造后**：收起态只有 **头像 + 昵称 + 身份**，点击展开下拉菜单。

| 状态 | 收起态显示 | 展开后菜单项 |
|:---|:---|:---|
| **已登录** | 头像（或首字母）+ 昵称 + 「男S · 试鞭」 | 面板头（昵称 / 邮箱 / 身份徽章 / 角色徽章）<br>👤 个人资料 → `/profile.html`<br>⚙️ 管理面板（仅 admin/subadmin）<br>🚪 退出登录 |
| **未登录** | 虚线头像占位 👤 + 「未登录」+「点此注册 / 登录」 | 面板头（游客模式说明）<br>🌿 注册 / 登录 → `/auth.html`<br>📖 了解规则 → `/about.html`<br>🚪 返回引导页 → `/landing.html`<br>提示「当前为游客浏览，部分内容与操作受限」 |

**交互细节**

| 行为 | 实现 |
|:---|:---|
| 点击展开 / 收起 | `#umTrigger` click |
| 键盘可达 | Enter / Space 触发；`aria-haspopup` / `aria-expanded` 同步 |
| 点击外部关闭 | `document` click 判断 `contains` |
| Esc 关闭 | `document` keydown |
| 窗口 resize 关闭 | 避免面板错位 |
| 面板动画 | 透明度 + `translateY(-8px)` + `scale(0.98)`，`transform-origin: top right` |
| 防重复绑定 | 触发区用 `dataset.wired` 标记；全局关闭逻辑只注册一次 |

**头像上传已从顶栏移出**，改到个人资料页统一处理。

### 3.2 新增个人资料页 `src/launcher/profile.html`

| 区块 | 功能 |
|:---|:---|
| **头像** | 96px 圆形，hover 显示「📷 更换头像」遮罩，点击选择文件 |
| | 校验：类型 `image/*`、大小 ≤ 5MB |
| | 上传：Canvas 压缩 → 200×200 WebP → Supabase Storage `avatars` 桶 → 写 metadata |

| **基本资料** | 昵称可编辑（≤24 字），改动后「保存修改」启用 |
| | 邮箱只读展示（作为登录凭据） |
| | 「还原」按钮回到原昵称 |
| | 保存后同步刷新 localStorage 会话，**其他页面立即读到新昵称** |
| **身份与等级** | 主身份（标签 + 定位 + 性别 + 上下位） |
| | 副身份（多标签展示） |

| **未登录态** | 游客提示卡 + 「🌿 注册 / 登录」+「先去逛逛」 |

**为后续编辑功能预留**：身份区已做成只读信息行，后续开放自助修改时直接替换为选择器即可。
