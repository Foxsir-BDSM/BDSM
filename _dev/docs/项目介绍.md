## 一、这是什么

**一个面向 BDSM 爱好者的私密社区平台。**

不是论坛，也不是社交软件。它解决三个具体问题：

| 问题 | 平台的答案 |
|:---|:---|
| 想找人，但圈子太杂、真伪难辨 | **欲渊之庭** —— 结构化档案库，信息真实且本人可控 |
| 想学东西，但网上内容零散、没验证 | **欲炼之途** —— 由圈内人撰写并标注风险等级的玩法库 |
| 担心隐私泄露，不敢写真话 | **五重隐私开关** —— 每一项都由你决定公开与否 |

**核心理念**：安全、尊重、共识。

## 二、两个板块

### 🌊 欲渊之庭 —— 档案库

回答"我是谁"。

- **身份体系**：男S / 女S / 男M / 女M —— 只此四种，不设模糊地带
- **档案内容**：基础信息、身体数据、关系状态、经历与偏好、影像资料
- **填写方式**：通过结构化问卷提交，约 110–150 题
- **浏览方式**：列表页按身份自动分流 —— **S 侧默认看到 M 侧，反之亦然**

### ⛓️ 欲炼之途 —— 玩法与见解

回答"能做什么"。

**四种内容形式**，按表达需要选择：

| 类型 | 适合什么 |
|:---|:---|
| 玩法任务 | 有明确步骤的实践玩法：场景准备、道具清单、具体事项、检查点 |
| 主题合集 | 围绕一个主题的多条目合集，如"某个道具的 N 种用法" |
| 分级清单 | 打分表 / 程度量表 / 问答清单，适合自评、对照、双方勾选 |
| 见解随笔 | 经验、感悟、科普、问答，自由表达 |

## 三、安全与隐私设计

这部分是这个项目最花心思的地方。

### 1. 五重隐私开关 —— 你的信息由你决定

档案里有五个独立开关：

```
是否公开问卷内容     是否公开常住地址     是否公开联系方式
是否公开生活照片     是否公开隐私照片
```

**关键规则**：未公开的字段，**任何人都看不到 —— 包括管理员**。

> 理由：公开与否是你的私人选择，不是权限层级问题。管理员能管理"公开与否"这个开关，但不能绕过它看内容。

### 2. 风险等级标注 —— 不拦截，但如实告知

每篇玩法都标注风险等级：

| 等级 | 含义 |
|:---|:---|
| 低 | 无身体损伤风险 |
| 中 | 有不适但可逆 |
| 高 | 可能造成可逆损伤，**须填写中止条件与后护理** |
| 极高 | 有不可逆伤害风险，**默认折叠展示，需知情确认** |

平台**不做内容拦截**，但对高风险内容强制要求作者写明安全边界。

### 3. 账号与档案的自动关联

不必手动绑定 —— 提交问卷时会自动带上账号信息，系统据此把档案归属到你名下。

## 四、怎么开始

```
着陆页  →  注册（选择身份）  →  首页
                                  ├─ 填档案 → 欲渊之庭
                                  └─ 看/发内容 → 欲炼之途
```

1. **注册**时选择你的身份（男S / 女S / 男M / 女M），这一个选择决定你在平台里的角色与档案展示规则
2. **首页**只有两个入口，没有多余干扰
3. **想填档案**：在欲渊之庭点「母の曝光」，完成问卷
4. **想发文**：在欲炼之途点发布，选一种内容形式
5. **想改资料**：在「我的」页面点头像旁的「编辑资料」

## 五、技术底座

| 项 | 说明 |
|:---|:---|
| 形态 | 静态多页面站点，无框架依赖，加载快 |
| 账号 | Supabase 认证，支持头像存储 |
| 档案数据 | 结构化表格服务（Zite / Fillout Tables） |
| 内容数据 | 存储在 GitHub 仓库，版本可追溯 |
| 页面数 | 17 个 |

**设计取向**：字段配置与页面代码分离。新增或调整某个页面显示哪些字段，只需改一处配置，不用动页面代码 —— 这让后续迭代成本很低。
