# 零、开工前必读

## 0.1 添加字段的方式

**单击**左侧字段类型面板里的按钮即可添加，**不需要拖拽**。

## 0.2 Zite 字段类型对照

| 本表用到的类型 | Zite 里选什么 | 数量 |
|:---|:---|---:|
| single_select | Dropdown（下拉单选） | 64 |
| long_answer | Long answer（多行文本） | 31 |
| linear_scale | Slider 或 Opinion scale（1–5） | 30 |
| multi_select | Multiselect（多选） | 18 |
| short_answer | Short answer（单行文本） | 13 |
| number | Number（数字） | 8 |
| file_upload | File uploader（文件上传） | 7 |
| date | Date picker（日期） | 1 |

## 0.3 章节标题怎么做

每章开头放一个 **Heading**（章标题）+ 一个 **Paragraph**（章说明）。
分组小标题用 **Paragraph** 加粗，或用 **Divider** 分隔。

## 0.4 条件显示怎么设

先建第 1 章第 1 题「你的身份是」（Dropdown，选项 男S/女S/男M/女M）。
**它是所有条件规则的引用源**，必须先建好。之后每题在右侧属性面板 **Logic** 里设 Show if：

| 条件 | Logic 表达式 | 题数 |
|:---|:---|---:|
| 仅 S 可见 | `Show if Q-GATE-01 is 男S OR 女S` | 46 |
| 仅 M 可见 | `Show if Q-GATE-01 is 男M OR 女M` | 17 |
| 仅女性可见 | `Show if Q-GATE-01 is 女S OR 女M` | 16 |
| 仅男性可见 | `Show if Q-GATE-01 is 男S OR 男M` | 5 |

## 0.5 本章提到的三处已知问题（按你的要求保留原样）

- `Q-E10` 最多几人同房 —— 条件指向已删除的 Q-E09，**不会显示**
